# Preuve de conception applicative

Cette fixture technique démontre la chaîne de conception sans code manuel.

- Un visiteur saisit une note et l'envoie depuis une page Web publique.
- L'API analogue Postman est une référence d'observation uniquement.
- L'API cible est un contrat explicitement planifié pour cette preuve.
- La réalisation doit exposer les états prêt, succès, erreur et hors ligne.

Cette fixture n'est ni un produit métier ni une spécification de Clean Street.
