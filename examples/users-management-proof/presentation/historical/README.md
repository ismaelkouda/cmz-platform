# Archives de présentation

Les ressources de ce dossier sont conservées pour la traçabilité des décisions,
pas pour guider une réalisation actuelle.

Archives enregistrées :

- [`adaptive-create-candidates/`](./adaptive-create-candidates/) : ancienne
  matrice géométrique de création et ancien protocole visuel C5 ;
- [`data-view-reference-candidates/`](./data-view-reference-candidates/) :
  anciennes maquettes de vue de données C5 mêlant disposition et capacités.

Règles obligatoires :

- toute archive porte `authority: none` dans un manifeste fermé et validé ;
- aucun chemin sous `presentation/historical/` ne peut apparaître dans un
  manifeste `presentation-evidence` actif ;
- une archive n'est ni une baseline visuelle, ni un contrat de capacité, ni un
  exemple de code runtime ;
- une intention encore utile doit être reconstruite depuis les contrats et
  autorités courants, puis soumise à une nouvelle validation produit ;
- un ancien hash prouve l'identité du fichier, jamais sa pertinence actuelle.

La politique courante est définie par
[ADR-0083](../../../../docs/adr/0083-preuve-page-exemple-mise-en-page-et-archive.md).
ADR-0082 reste consultable comme étape historique de cette décision.
